Sorteio Doce Veneno

App de sorteios da loja integrado ao Instagram, com sorteio ao vivo e painel de estatísticas.

React 19ViteExpress 5Node.jsInstagram APIVercel

Visão Geral

Aplicativo para realizar sorteios reais da loja Diretamente integrado ao Instagram. O backend em Express 5 consulta os comentários de uma publicação via Instagram API e o frontend em React 19 roda o sorteio ao vivo, com animação, confete e histórico.

Funcionalidades

  • Sorteio ao vivo com animação e confete
  • Integração com a Instagram API (participantes de posts)
  • Lista de participantes e validação
  • Histórico de sorteios e registro de vencedores
  • Painel de estatísticas
  • Deploy na Vercel (front + serverless)

Ficha técnica

  • TipoFullstack
  • FrontendReact 19 + Vite
  • BackendExpress 5 / Node
  • IntegraçãoInstagram API
  • DeployVercel
