EscolarBH

Plataforma completa de transporte escolar: painel web, API, app mobile e serviço de geolocalização.

ReactTypeScriptSpring BootKotlinReact NativeExpoRustPostgreSQLDocker

Visão Geral

Projeto Fullstack de larga escala dividido em quatro serviços: o painel web para administradores (React + TypeScript), a API de negócio (Spring Boot em Kotlin), o app mobile para motoristas e pais (React Native + Expo) e um microsserviço de geolocalização em Rust. O objetivo é conectar motoristas, pais e escolas no acompanhamento do transporte escolar em tempo real.

Funcionalidades

  • Login + dashboard com mapa em tempo real
  • Navegação por tabs conforme o papel (motorista vs pai)
  • Check-in / check-out de alunos no embarque e desembarque
  • Gestão de contratos e pagamentos
  • Push notifications com Firebase Cloud Messaging
  • Microsserviço de geolocalização em Rust
